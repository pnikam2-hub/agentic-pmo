# Green Methanol — Biomass Gasification Pathway

**Domain Pack for Agentic PMO**

This pack provides project management and AI agent context for a **green methanol production facility** using the **biomass gasification pathway**.

## Contents

| File | Description |
|------|-------------|
| `playbook.md` | Full project lifecycle with 8 phase-gates (Phase 0–7) |
| `agent_context.md` | Agent instructions for Plan, Monitor, Alert agents |
| `wbs_template.json` | 80+ task work breakdown structure across 15 disciplines |
| `risk_register.json` | 50+ project risks with mitigation and contingency |
| `permitting_checklist.json` | Permit requirements (India-aware, adaptable) |
| `procurement_checklist.json` | Equipment procurement packages with vendor criteria |
| `commissioning_checklist.json` | Commissioning sequence with safety hold points |
| `monitoring_rules.json` | PMO alert rules with severity and actions |
| `kpi_definitions.json` | Schedule, technical, and quality KPIs |

## How to Use

1. Create a new project in Agentic PMO
2. Select **"Green Methanol - Biomass Gasification Pathway"** from the template list
3. The system creates 80+ tasks across all phases and disciplines
4. Run the Plan Agent for AI-generated planning (requires LLM API key)
5. Apply risk register and monitoring rules for ongoing tracking

## Key Assumptions

- Feedstock: agricultural residue, forestry residue, or organic biomass waste
- Gasification: fixed bed, fluidised bed, or entrained flow (configurable)
- Oxidant: air, oxygen, oxygen-steam (configurable)
- Methanol synthesis: copper catalyst, fixed bed or boiling water reactor
- Product: fuel-grade green methanol meeting IMPCA specification

## Important

This pack is a **project management reference tool**. It does **not** provide engineering certification, detailed process design, or legal advice. All content must be reviewed by qualified professionals before use on a real project.
